# Bridgr UX audit — 2026-07-11

Audience: polyglots / expats who outgrew Duolingo, want Babbel-level quality without a tutor.
Tone contract: encouraging, adult, zero guilt. Streaks are **weekly**.

Legend: **P0** = broken/blocking · **P1** = hurts trust or comprehension · **P2** = polish

---

## P0 — Language context is broken app-wide

1. **Switching language doesn't stick.** The Learn switcher only sets `?lang=` on `/learn`.
   `learning_languages.last_accessed_at` is written exactly once (course creation:
   `app/api/placement/submit/route.ts:200`, `lib/beginner-course-flow.ts:35`), so Practice,
   Review and the session fallback always resolve to whatever course was created last —
   not what the user picked. **Fix:** persistent switcher that bumps `last_accessed_at`.
2. **Practice content ignores the learning language.** `app/practice/page.tsx` counts due
   flashcards across *all* languages; `lib/srs.ts#getDueCards` has no language filter, so a
   Spanish review queue can serve German cards. For a polyglot audience this is the #1
   credibility killer. **Fix:** filter both by active `language_code`.
3. **No always-visible language context.** The switcher renders only with 2+ languages, and
   only on Learn. **Fix:** Duolingo-style flag selector in the top-right of Learn and
   Practice, always visible, with "Add a new language" inside the menu.

## P0 — Dark mode is broken inside the core learning loop

4. `SessionStage1Card` options: `bg-white / border-slate-200 / bg-lime-50 / bg-red-50` —
   glaring white cards on the near-black app background.
5. `SessionStage2Card`: `bg-white` input, white hint popover, correct answer in
   `text-slate-700` (unreadable on dark).
6. `SessionDeck` completion: score line in `text-slate-600` (≈ invisible).
7. `FalseFriendAlert`: hardcoded `#1a3d38` card, `text-slate-600` body (fails contrast),
   light-mode-only chips, ⚠️ emoji as icon.

## P1 — Contrast fails WCAG at the token level

8. `--text-secondary: rgba(255,255,255,0.32)` ≈ 3:1 on `#1a1a1a` — fails 4.5:1 for body
   text; the entire app's secondary text is too dim (same issue in light mode at 0.32
   black). **Fix in tokens once, lifts every screen.**

## P1 — Feedback, loading, empty states

9. Session-complete screen buries the win: broken-contrast score line, no accuracy, no
   link back to the week goal, single "Back to home". Should celebrate calmly: accuracy,
   words locked in, week progress, clear done/continue.
10. Loading states are bare text ("Loading practice...", "Loading due cards...") on
    Practice/Review; error states are raw red strings with no retry.
11. Emojis used as UI icons (⚠️ ✓ 💡) in review + false-friend screens; hint color is a
    hardcoded `#ffd166`.

## P1 — Small interaction debt

12. Profile: remove-language ✕ is a ~24px target (needs ≥44px); debug copy "No achievement
    rows yet." ships to users.
13. No visible focus states anywhere except the shadcn button (keyboard users are lost).
14. `/todos` is a live leftover template route querying a `todos` table.
15. BottomNav labels at 9px are below readable minimum; tap area is fine but tight.

## P2 — Visual system drift (why it doesn't feel premium)

16. `#BFFF00` / `#2A3800` / `#A8E000` hardcoded in ~25 files instead of tokens; Tailwind
    already defines `lime` tokens that nothing uses.
17. Radius roulette: `rounded-[9px]`, `rounded-[12px]`, `rounded-lg(18)`, `rounded-xl(22)`,
    `rounded-2xl`, `rounded-[22px]` all coexist on sibling elements.
18. Cards are flat `--card` rectangles with no border/elevation; sections separated only by
    margin — reads unfinished rather than minimal.
19. Two shadcn-style variants in `components/ui/button.tsx` reference tokens that don't
    exist in this Tailwind config (`bg-secondary`, `text-foreground`…) — silent no-ops.

## What was changed in this pass

- **Tokens** (`app/globals.css`, `tailwind.config.ts`): readable secondary/tertiary text,
  semantic Tailwind aliases (`bg-card`, `text-ink-*`, `bg-accent-fill`, `text-accent-ink`,
  `border-line`), shared component classes (`btn-primary`, `btn-secondary`, `card`,
  `chip`, `label-caps`), global `:focus-visible` ring, `prefers-reduced-motion` support.
- **Language switcher** (`components/LanguageSwitcher.tsx` + `components/AppHeader.tsx`):
  always-visible flag chip, top-right on Learn and Practice; menu lists courses with CEFR
  level + "Add a new language"; selection persists by bumping `last_accessed_at`.
- **Practice is language-aware**: due count and review queue filter by the active language.
- **Session loop restyled for dark/light** with tokens; false-friend alert redesigned;
  session-complete screen now shows accuracy + locked-in words and calm, adult copy.
- **States**: skeleton loading + recoverable error states on Practice and Review.
- **Cleanups**: `/todos` route deleted, profile debug line removed, touch targets ≥44px,
  BottomNav labels bumped, radii normalized on touched screens.

## Ops note (2026-07-11)

`next build` used to write into the same `.next` dir a running `next dev` server uses,
crashing the app ("app down after clicking Profile" was this). `next.config.js` now sends
production builds to `.next-build`, so builds and the dev server can't clobber each other.
